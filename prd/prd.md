1. 프로젝트 개요
제목: 수상한 연구소
장르: 포인트 앤 클릭 방탈출 시뮬레이션
플랫폼: 모바일 반응형 웹(가로 화면 고정, 세로 차단)

2. 핵심 게임 규칙
a. 어떤 스마트폰에서도 클릭요소의 위치가 달라지지 않도록 그림 내에서 클릭 요소의 좌표 위치가 설정되어야한다.
(예를 들어 아이폰 미니와 아이폰 프로의 경우 화면 비율이 다를 수 있는데 이 때 그림 내의 손수건을 클릭하려고 할 시, 화면 비율이 달라져서 다른 요소가 클릭되는 오류가 있어서는 안됨.)
b. 그림 내에는 그림을 클릭할 수 있는 요소 외에는 어떤 요소도 있어서는 안된다. (예를 들어 메뉴 버튼, 인벤토리 버튼, 힌트 버튼, 이동 버튼 등)
c. 모든 그림의 비율은 가로 4: 세로 3의 비율이다. 이 때 그림이 어느 곳도 가리지 않도록 화면 내 중앙에 배치되도록 하고 남는 좌측과 우측에는 이동 버튼을 배치한다.
d. 좌측 이동 버튼은 좌측에, 우측 이동 버튼은 우측에 배치한다. 우측의 상단에는 메뉴 버튼과 인벤토리 버튼을 나란히 배치한다.
e. bg(background)에서 특정 요소를 클릭해서 화면이 이동했을 시에는 뒤로 가기(back) 버튼이 활성화되도록 한다.
f. 어떤 요소든 사용하고 더이상 필요가 없다면 다시 재클릭 했을 때 "이건 더이상 살펴볼 필요가 없을 것 같아" 라는 대화창이 표시되도록 한다.
g. 점수는 0점부터 시작하며 힌트를 쓸 때마다 점수를 5점씩 차감한다. (마이너스 점수도 가능하다.) 그리고 어떤 정답 요소를 입력해서 맞출 때마다 10점을 준다.
h. C:\Users\sohee\project\renewable_escape_room\prd\Touch Target을 면밀히 분석해서 터치 가능 영역을 먼저 확인한다.
i. 인벤토리 창의 모든 아이템은 클릭 시 상황에 맞게 선택해서 사용되거나 확대해서 화면에 보여질 수 있다. 확대해서 화면에 보여질 때는 C:\Users\sohee\project\renewable_escape_room\scene\inventory의 이미지를 활용하면 된다. 그 중 item_04_album을 클릭했을 때는"C:\Users\sohee\project\renewable_escape_room\scene\room_b\b_3c_s1_left_only.png" 화면으로 이어질 수 있도록 한다. 확대했다가 돌아가기 버튼을 통해 다시 게임으로 돌아가도록 한다.
j. 한 번 단계를 끝난 단계의 경우 맨 마지막 화면만 다시 보여준다. (예를 들어 소파 장면의 경우 면도날로 뜯어서 확보한 메모를 다시 보고 싶은 경우를 대비하여)
k.prd\UI, UX example 폴더 내 사진 등을 반드시 확인하고 ui, ux를 설계할 것

3. 디렉터리 구조

scene/
├── global/          ← 전역 효과음
├── iconpack/       ← 아이콘 모음
├── inventory/       ← 인벤토리 아이템 이미지
├── ending/          ← 엔딩 화면
├── room_a/          ← 장면 A (창문·라디오·도어락 면)
├── room_b/          ← 장면 B (서류함·책상·선반 면)
├── room_c/          ← 장면 C (냉장고·싱크대·사다리 면)
├── room_d/          ← 장면 D (배전반·소파·면도칼 면)
└── yard_e/          ← 장면 E (마당)

4. 파일명 규칙

[장면]_[구역]_[상태].png          ← 이미지
[장면]_[구역]_sfx_[설명].[ext]     ← 사운드
[장면]_[구역]_video_[설명].mp4 ← 영상

| 토큰 | 값 | 설명 |
|------|----|------|
| `[장면]` | `a` `b` `c` `d` `e` | 장면 코드 |
| `[구역]` | `bg` `1a` ~ | 구역 번호 (bg=배경 전체) |
| `[상태]` | `dark` `light` | dark=어둠, light=밝음 |
| `sfx_` | (접두) | 사운드임을 표시 |
